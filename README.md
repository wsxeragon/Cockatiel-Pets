# 🐤 Cockatiel-Pets (玄凤鹦鹉桌面宠物) DEMO版

一个基于 **Python + PySide6 (Qt)** 开发的软萌像素风玄凤鹦鹉轻量级桌面陪伴宠物。

拥有**透明通道无边框置顶窗口**、**四维心态动力学引擎**、**丰富生物习性微表情**与**心理雷达监视器**。

## ✨ 核心特色

### 1. 软萌像素风 Q 版形象 (100×80)
- 坚持经典“麻糬大福”圆滚滚 Q 版造型，桌面悬浮置顶，小巧精致不遮挡日常办公。
- 左右朝向自适应镜像，全透明通道背景渲染。

### 2. 生物拟真动作与微表情系统
- **鸭子步踱步 (`waddle`)**：外八字左右微倾摇摆鸭子步 + 短尾反向甩动，憨态可掬。
- **低头求摸毛 (`bow`)**：惬意舒适的弯弯笑眼 `(^_^)` 与微晕红脸蛋，撒娇感十足。
- **母鸡蹲熟睡 (`sleep`)**：双脚完全收纳进肚皮羽毛下（经典“农民揣/母鸡蹲”），呼吸微微起伏。
- **流线型飞行 (`fly`)**：双爪紧贴肚皮收拢破风，扇翅动作富有张力。
- **心形翅膀独奏 (`sing`)**：玄凤招牌“心形翅 (Heart Wings)”半张低垂，翘尾大声吹口哨啼唱。
- **啄地顿挫感 (`peck`)**：嘴尖触地瞬间前突加重顿挫，尾部反弹，敲击感清脆。
- **拆家搞事 (`chew`)**：啃咬屏幕边缘，精力充沛时的淘气破坏。

### 3. 五维心态动力学引擎 (Mood Dynamics)
采用非线性心理动力学状态机，包含五项相互影响的心理与生理指标：
- **惊吓 (Fright)**：受到打扰或逼近时上升；惊吓值 > 80% 察觉光标靠近会立即惊慌飞逃；惊吓值 $\ge 50\%$ 拥有一票否决权（无法入睡）。
- **舒适 (Comfort)**：被抚摸头颈部会积累，带来安心信任感。
- **兴奋 (Excitement)**：闲置积蓄或被逗乐时激增；兴奋动作结束后自动清空；兴奋状态下疲劳消耗速度提升 2 倍。
- **平静 (Calm)**：由其余各维压力动态平衡计算基准态。
- **疲劳 (Fatigue)**：
  - 醒着时随时间每分钟自然累积 $+1.0$ 点；
  - 疲劳度 $> 50\%$ 且惊吓度 $< 50\%$ 时概率性触发入睡；
  - 疲劳度 $> 90\%$ 强制终止当前一切动作当场秒睡；
  - 熟睡期间平缓恢复体力，睡饱（疲劳 $\le 25\%$）自然醒来伸展。

### 4. 实时心理雷达监视器 (Radar HUD)
- 独立配套 HUD 窗口，实时绘制四维心态多边形雷达图与疲劳度进度条。
- 提供直观的调试注入工具：
  - `摸头 (+舒适)` / `戳身子 (+惊吓)`
  - `模拟长时闲置 (+精力)` / `强制兴奋自嗨`
  - `💤 强制睡眠` (疲劳拉满秒睡) / `⚡ 清空疲劳` (瞬间回满清醒)

## 🎮 桌面交互指南

| 交互方式 | 触发区域 / 动作 | 鹦鹉反应 |
| :--- | :--- | :--- |
| **摸摸头** | 鼠标点击头颈部安全区 | 增加舒适度，抚平惊吓，开心享受 |
| **悬停求摸** | 鼠标在头顶悬停 $> 0.6$ 秒 | 主动低头眯眼微笑求撸毛 |
| **戳身子** | 鼠标点击腹部/翅膀禁区 | 闪电反咬警告；短时间内连戳 3 次触发暴怒哈气与惊飞 |
| **应激躲避** | 惊吓值 $> 80\%$ 时鼠标逼近 | 察觉到光标靠近（120px 内）立刻惊叫扇翅飞逃远离 |
| **拖拽移动** | 鼠标左键按住鸟身拖动 | 随意移动摆放在屏幕任意位置 |
| **右键菜单** | 鼠标右键点击鹦鹉 | 开关雷达面板、逗它唱歌、强制入睡、清空疲劳、退出程序 |

## 🚀 快速启动

### 依赖环境
- Python 3.10+
- 推荐使用 Windows 10/11 系统

### 安装依赖
```bash
git clone https://github.com/wsxeragon/Cockatiel-Pets.git
cd Cockatiel-Pets
pip install -r requirements.txt
```

### 启动桌宠
```bash
python main.py
```
> **Windows 用户便捷方式**：可以直接双击根目录下的 `run_pet.bat` 无终端窗口静默启动。

## 📂 项目结构

```text
├── main.py                     # 程序启动入口 (初始化桌宠与雷达监视器)

│   └── sprites/                # 桌宠当前运行使用的 100x80 全套 37 张关键帧切片
├── 2d-new/
│   ├── preview.html            # 浏览器双轨对比审帧工具 (支持逐帧循环、倍率与朝向调节)
│   └── sprites/                # 优化版序列帧库
├── backup_original/            # 初始原画帧备份归档
└── README.md                   # 项目说明文档
```
